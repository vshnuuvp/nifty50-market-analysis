# NIFTY 50 Market Analysis Dashboard

## Overview

A Python-based financial analytics project designed to collect, analyze, and visualize NIFTY 50 market data. The project provides market insights and performance metrics using real-world stock market data.

---

## Current Features

✅ Fetch NIFTY 50 historical market data using yfinance

✅ Calculate:
- 1 Month Return
- 6 Month Return
- 1 Year Return
- 5 Year CAGR
- 10 Year CAGR

✅ Generate Market Overview Report

✅ Visualize NIFTY Closing Prices

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- yfinance
